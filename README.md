# Twier
Twier is a social media you can claim a word by posting it. A word can be
any string of letters separated by non-letters. After claiming a word,
nobody else can use it.

## Setup app
Run
```
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Run app
In app directory, run
```
python3 ./main.py
```
